# Security policy

Nayak handles accounts of elected representatives and their staff. Please report security problems privately.

- Use GitHub: **Security tab -> Report a vulnerability** (private advisory), or contact the repository owner directly.
- Do not open a public issue for a vulnerability and do not post credentials, tokens or personal data anywhere.
- We acknowledge reports within 3 working days.

How the system protects itself (argon2id passwords, per-account lockout, server-side role scoping, audit log) is described in `docs/PRODUCT_MAP.md` and `docs/PROJECT_GUIDE.md`.
