# Contributing

This is a proprietary project (see `LICENSE`). Access is by invitation.

1. Read `docs/PRODUCT_MAP.md` (features, permissions, API) and `docs/PROJECT_GUIDE.md` (how it is built).
2. Branch from `main`, keep changes small, open a pull request using the template.
3. Run the checks in the template. Tests use a throwaway Postgres, never a real database.
4. Never commit secrets, `.env` files or real people's contact data.
